{% include rule.html label="terminal tools" %}

Small, offline-first terminal software — stdlib-only, single-file where possible, with offline test suites. The shared bar: no network on the read path, and code a single person can audit in an evening.

shinbun

The daily newspaper as one dated 80-column plaintext file: pulled over tor each morning by a jittered timer, read back offline with zero network on the read path, and yesterday's file is the archive. The whole program is one stdlib-only file — hand-rolled SOCKS5 client with remote DNS, minimal HTTP/1.1 reader, blend-in user agent, exactly four GETs per edition — with a fail-closed mode for unattended pulls. The offline-first creed, end to end, in a single auditable file.

sdwx

Weather, surf, tides, sun/moon, and space weather in one 80-column report — stdlib-only Python, keyless APIs, per-source caching with stale-if-offline fallback, and graceful per-section degradation. Built for a tmux pane or a shell login hook; the test suite never touches the network.

yomu + sokudoku

A ~450-line, standard-library-only EPUB reader for the terminal — parsed by hand from zip to spine, with the comments teaching the format as they go; the reader is also the documentation. sokudoku is its flashing-word counterpart: an rsvp speed reader whose pacing follows the reading research rather than the app marketing — sentence-boundary-aware flashes, rewind-to-sentence-start on resume, honest about regression. No network, ever.

tidepool

A live binaural-beat player in one file: named modes instead of raw frequencies, vim keys, phase-continuous synthesis with click-free mode switches — and honest sourcing, flagging where the entrainment evidence is weak instead of selling wellness.

dotfiles-public

A minimal, plaintext-forward Debian/Wayland desktop starter — sway, waybar, fuzzel, and a live theme system. Deliberately small: no installer, nothing needs sudo, and nothing touches the system outside $HOME.

chr0nix

Normalizes incident exports into UTC-ordered, hash-manifested exhibit indexes — one defensible timeline instead of scattered logs and notes.

cust0dia

Recursive SHA-256 exhibit manifests with chain-of-custody log generation — every artifact hashed, every handoff recorded.

h4ndl3

Offline-first identifier research worksheets with validated, corroboration-tracked findings — lawful, documented open-source research by default.

m3talex

Image metadata extraction and synthetic-media indicator flagging — what a file says about itself, and when that story doesn't add up.

traxerax-lite

Self-contained Linux host defense and audit: multi-source log correlation, live host telemetry, configuration and hardening audits, file integrity monitoring, and cross-run change detection — plus an optional eBPF kernel probe that surfaces rootkit and compromise indicators. Behavioral detection, no signatures, no network calls: host state turned into a structured account of what changed and what actually matters.

lab-writeups

70+ documented offensive-security lab engagements (hackthebox, proving grounds, tryhackme), redacted for public release. Fourteen Active Directory boxes running full kill chains — null-session enumeration to AS-REP roasting to DCSync, Kerberoasting, ADCS and ACL abuse, BloodHound path reasoning, password spraying under lockout constraints — plus ~50 Linux and 10 Windows targets covering web exploitation, LFI-to-upload chains, and SUID/GTFOBins privilege escalation. Every writeup closes with root cause, impact, remediation, and detection opportunities: offense written to inform defense, and every claim traceable to a command, a log, or a screenshot.

hakiki

A command-first offensive quick reference distilled from repeated lab work — 29 pages across recon, web exploitation, credentials, exploit dev, reversing, privesc, Active Directory, and post-exploitation. The AD page runs the full kill chain with exact invocations; noisy techniques carry an explicit PT-only tag. Commands and decision points that keep analysis consistent instead of improvised. Authorized use only.

p0rtix

A scope-aware enumeration framework, runnable standalone (interactive TUI or headless CLI) or over MCP, with evidence preserved as raw command logs — the discipline of scoped, authorized work where every action is logged and exportable.

sliver-mcp + p0cs

The rest of the ai-offsec stack: sliver-mcp exposes the sliver c2 operator surface — listeners, implant generation, sessions, command execution — as MCP tools an ai agent can drive behind an explicit safety gate, and p0cs is a uniform runner for proof-of-concept exploits and offensive helpers, stdlib-only, with no hardcoded targets and a runner that refuses to launch without them. Adversary emulation for defenders, with authorized-use gating throughout.
