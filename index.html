I find what doesn't belong, I prove it, and I make it hold up — with people, with systems, and with code.

The skill is behavioral and it transfers: rapid, behavior-based assessment honed over ~6 years of security fieldwork (overt/covert, cctv, plainclothes, armored), a year of rural 911 ems, 70+ offensive lab engagements, and a behavioral host-defense tool with a handwritten ebpf probe. Every side of an incident — responded to as an emt, watched through a camera wall, tailed in plainclothes, documented for court, replayed in a lab. The way I work is the other half of the offer: offline-first, stdlib-only tools you can audit in an evening, and documentation that makes evidence hold. low-resource, high-capability — the read path never needs a network, and neither do I.

{% include rule.html label="terminal software" %}

Python (stdlib-first), bash, some C — single-file tools with offline test suites and documentation meant to be read, not just rendered. shinbun is the daily newspaper as one dated 80-column file, pulled over tor each morning and read fully offline — hand-rolled SOCKS5 and HTTP, a blend-in user agent, and a fail-closed mode for unattended pulls. sdwx packs weather, surf, tides, sun/moon, and space weather into one 80-col report with no API keys and a stale-cache fallback when the network is gone. yomu is a ~450-line EPUB reader whose comments teach the format as they go, and sokudoku is its flashing-word counterpart — an rsvp speed reader whose pacing follows the reading research rather than the app marketing. tidepool is a binaural-beat player with named modes, vim keys, and phase-continuous synthesis, honest about what the science does and doesn't support.

{% include rule.html label="systems & host defense" %}

Linux internals, x86 assembly, eBPF, bubblewrap sandboxing, kernel hardening — prefers understanding systems below the api layer. traxerax-lite is behavioral Linux host defense and audit: anomaly-based, no signatures, no network calls, with a handwritten eBPF probe and candid known-limitations.

{% include rule.html label="offensive security" %}

70+ documented lab engagements (hackthebox / proving grounds / tryhackme), redacted for public release. Active Directory end to end — AS-REP roasting, Kerberoasting, DCSync, ADCS and ACL abuse, BloodHound path reasoning, password spraying under lockout constraints — plus web exploitation, Linux and Windows privilege escalation, and exploit-dev / reversing fundamentals. Authorized labs only; the writeups are the discipline. Every engagement closes with root cause, impact, remediation, and detection opportunities, because offense that can't inform defense is just trivia. lab-writeups carries the evidence; hakiki is the command-first field reference distilled from the same reps. The methodology also ships as tooling: an ai-offsec stack of MCP servers — p0rtix (scope-aware recon), sliver-mcp (the sliver c2 operator surface, agent-drivable), and p0cs (one uniform poc runner) — that lets an ai agent drive the kill chain under explicit safety gates. Authorized use only, everywhere.

~6 years of contract security — physical, overt, covert, cctv / video surveillance; hands-on to hands-off, armed to unarmed, uniformed to plainclothes, armored / cash-in-transit — and one year as a 911-response emt in a rural, low-resource system.
